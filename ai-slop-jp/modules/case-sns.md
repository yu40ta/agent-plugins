# Case: SNS 主張文 (Threads/X/FB 投稿・告知・キャッチコピー)

## 目的関数

タイムラインで指を止めさせ、書き手の声で一点を刺す。数行で言い切る。

## 適用

- 人間らしさ: 全 8 要素 ◎ (コア §3)
- 採点: 5 軸フル。合計 35/50 未満は書き直し
- 書き手の声: 本人名義なら (用意していれば) 自分の声のプロファイルの register に従う。**ペルソナアカウントならそのアカウント専用のプロファイル・NG 定義を使う** (本人の声プロファイルは使わない)

## 2 つの型 (規範ではなく選択肢)

- **フック先行型**: 結論・断定の一撃で始め、指を止めさせる
- **報告調型**: 「〜で登壇してきた」と淡々と報告する。テンプレ感想と悟り締めを排し、語尾と立場に温度が残っていれば成立する

どちらを採るかは書き手の好み。フックを弱めること自体は品質低下ではない。好みが未確認なら書き手に確認し、確認できない文脈 (自己精査等) ではフック先行型を既定にする。

## 種別固有 deny (機械ゲートへの追加)

| 症状 | 検知 | 処置 |
|---|---|---|
| ハッシュタグ盛り | # が 4 個以上 | 効く 1〜2 個に絞る |
| 拡散のお願い | 「拡散希望」「RT お願いします」 | 削除。中身で拡散させる |
| 一投稿多主張 | 判定質問「主張を一行で言えるか」→ 言えなければヒット | 一番言いたい一点に絞り、残りは別投稿へ |
| 全方位の書き出し | 「〜な人も多いのではないでしょうか」 | 特定の一人への断定に |

**告知の温度** (provisional・n=1): 立ち上げ・イベント告知で盛り上げを狙う場合は、イベント絵文字・「!」を通常より多めに許容してよい (削るのは飾り罫線・バズワードスローガンのみ。詳細は case-chat の「誤検知の境界」参照)。

## 較正実例 (実データ・採点付き)

### 実例 1: 前置きと留保を切る (Threads・実投稿の改稿 diff)

**before** (32/50 → 書き直し):

> 求人票に書けないリアル、書く。私は今フルリモート×残業10h以内で働いてるが、正直デメリットもある。フルリモートOKで転職した女性が、3年後に出社組と年収で100万以上差がついた話、採用担当として何十件も聞いてる。原因は「近接バイアス」。

採点: 立場 5 (「デメリットもある」の両論併記臭) / リズム 6 / 主体性 8 / 具体性 8 / 削減 5 (自己言及の前置き)

**after** (43/50・投稿確定稿):

> 「フルリモート=自由」はウソ。自由になるのは時間や場所だけで、年収は別の話だよ。採用担当として断言する。フルリモートOKで転職した女性が3年後に出社組と100万以上差がついた話、何十件も見てる。原因は「近接バイアス」。

採点: 立場 9 / リズム 8 / 主体性 9 (「断言する」の立場宣言) / 具体性 9 / 削減 8

直した点: 自己言及の前置き (「リアル、書く」) を断定の一撃に / 留保 (「正直デメリットもある」) を切った / 「聞いてる」→「見てる」で当事者性を上げた。
※ ペルソナ稿のため語尾はアカウント profile 準拠。ここでは**構造の直し方**だけを較正に使う。

### 実例 2: 文末単調を崩し、書き手の声を残す (X・本人確定稿)

**before** (30/50 → 書き直し):

> AWS Japan 主催の生成AI Frontier Meetup で登壇してきました。金融のレガシーシステムを Claude Code でリバースエンジニアリングした事例です。まずは組織全体に AI-DLC を浸透させ、業界全体を盛り上げていきたいです。

採点: 立場 6 / リズム 4 (です 3 連続・文長均一) / 主体性 6 / 具体性 7 / 削減 7 (「全体」の重複)

**after** (41/50・本人確定稿):

> AWS Japan 主催の生成AI Frontier Meetup で登壇してきた。金融のレガシーシステムを Claude Code でリバースエンジニアリングした事例。まずは社内に AI-DLC (aidlc-workflows) を浸透させ、業界を盛り上げる起爆剤をどんどん出していきたいものですな。

採点: 立場 7 / リズム 9 (常体 → 体言止め → 崩しの緩急) / 主体性 9 (「ものですな」= 声の癖) / 具体性 8 (固有名 aidlc-workflows) / 削減 8

直した点: 「組織全体/業界全体」の重複を「社内/業界」に振り分け / 文末を常体 → 体言止め → 「ものですな」で崩した / **書き手固有語は消さず保持** (声のプロファイルで頻度上限を決めているなら、その範囲内で)。

### 実例 3: テンプレ感想は一次体験に置換 — 素材は書き手から引き出す

**before** (12/50 → 全面書き直し):

> 先日、◯◯ Meetup に参加しました! たくさんの刺激をいただき、学びの多い時間でした。登壇者の皆様、運営の皆様、ありがとうございました! 私も頑張ろうと思います💪

採点: 立場 2 / リズム 4 / 主体性 1 / 具体性 2 / 削減 3。機械ゲートだけで 4 ヒット (テンプレ感想・「!」連発・絵文字・悟り締め)。

**after** (書き手ヒアリングで「1 時間半立ちっぱなしで登壇」「主催チームがご飯を取ってきてくれた」を引き出せた場合):

> ◯◯ Meetup で登壇。1 時間半立ちっぱだったので、主催チームの方々が心配してご飯取ってきてくださってましたｗｗ (以下、引き出した体験で構成する)

**この after は書き手から引き出した実体験だけでできている**。引き出せなければこうは書けない — 創作で埋めず、立場と温度だけで立てる (コア §6 鉄則 1)。

## 連作 (スレッド・連投) の注意

隣の投稿と分量・文体・敬体常体を実測して揃える (コア §6 鉄則 4)。1 投稿だけ凝ると浮く。
