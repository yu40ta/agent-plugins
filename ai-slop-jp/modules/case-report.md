# Case: 報告書 (業務報告・評価入力・稟議・議事要旨)

## 目的関数

判断に必要な事実が最短で伝わる。読み手 (上長・関係部署) が次のアクションを決められる。

## 適用

- 効く要素: H2 一次体験 ◎ (**事実として**書く — 感想としてではない) / H5 読み手 ○ (決裁者・宛先を想定) / H1 立場 ○ (評価・提言のパートでは逃げない)
- 殺す要素: H4 ムラ・H8 時間性 ✗。H3 温度は △ (所感 1 行までは可)
- 採点軸: 立場・具体性・削減。平均 7.0 未満は書き直し
- 本人 register: (用意していれば) 自分の声のプロファイルの register に従う (「私」・断定調・へりくだり無し、が既定)

## 種別固有 deny (機械ゲートへの追加)

| 症状 | 検知 | 処置 |
|---|---|---|
| 成果の抽象化 | 「多くの学びを得た」「大変有意義だった」「知見が深まった」 | 学び・成果の中身を数と固有名で書く |
| 決意表明で締める | 「今後の業務に活かしていきたいと思います」 | 次アクション (何を・いつまでに) に置換 |
| 責任回避の受動態 | 「〜と思われる」「〜が期待される」の乱用 | 主語を立てて言い切る。不確実なら根拠と確度を書く |
| 網羅の平坦列挙 | 判定質問「読み手の判断に効く項目とそうでない項目が同じ分量か」 | 効く項目に厚みを寄せ、残りは 1 行 |
| 形容詞ぼかし | 文字列: 甘め・厳しめ・〜めに (操作の実態を形容詞でぼかす) | 実態を動詞で直接書く (甘め→水増しする) |
| 稟議の願望止め | 文字列: 「〜を図りたい」「〜を推進したい」 | 動作で言い切る (例: 個別申請を包括承認に切り替える) |

## 較正実例 (採点軸: 立場 / 具体性 / 削減)

### 実例: イベント参加報告 — 感想を事実と提言に置き換える

**before** (平均 2.0 → 書き直し):

> 本イベントへの参加を通じて、多くの学びと気づきを得ることができました。他社の先進的な取り組みは大変刺激になりました。今後の業務に活かしていきたいと思います。

採点: 立場 2 (何も主張していない) / 具体性 1 (中身ゼロ) / 削減 3。機械ゲート 3 ヒット (成果の抽象化・テンプレ感想・決意表明)。

**after** (平均 8.3):

> 収穫は 2 点。
> (1) ◯◯社は評価データの匿名化を前処理でなく権限設計で解いていた。当社の △△ 案件に同じ構成が使える。
> (2) 生成 AI の社内浸透は「教育を先にやる」より「業務フローに埋め込む」が先、という確信を得た。◯◯社・□□社とも研修単体では定着しなかったと明言していた。
> 次アクション: △△ 案件の権限設計を 7 月中にレビューする (私が起案)。

採点: 立場 8 (「教育より埋め込みが先」と言い切り、根拠つき) / 具体性 9 / 削減 8

直した点: 「多くの学び」を 2 点の中身に展開 / 決意表明を期日つき次アクションに / 伝聞は出典 (誰が言ったか) を付けて断定と区別。

### 実例: 提言の立場軸 — 権限内は言い切り、権限外は示唆に留める

**before** (平均 3.7 → 書き直し):

> 評価制度全体の見直しを私が主導し、来期中に新基準を導入します。要因は評価運用のばらつきによる影響とみられます。対応: 評価基準の再設計、対象部署の絞り込み。

採点: 立場 3 (権限外の全社提言に「私が主導」「来期中に」を書いてしまっている) / 具体性 3 (「再設計」「絞り込み」が名詞句止まり) / 削減 5。判定質問「主体・期日を確定できる権限がある提言か」→ no (評価制度は人事部門の所管)。

**after** (平均 7.7):

> 評価制度全体の見直しは人事部門の所管のため、ここでは論点を示すに留める: 評価基準の運用にばらつきがある部署ほど、満足度スコアが低く出ている (集計は別紙参照)。評価基準の運用ルールをそろえる案を人事部門へ提出することを提案する。自分の担当範囲 (新人研修) では、来月の説明会に評価基準の解説を追加する (実施は私が行う)。

採点: 立場 8 (権限内は言い切り・権限外は提案止まりで書き分けている) / 具体性 8 (「そろえる案を提出する」まで動作で展開) / 削減 7

直した点: 権限外の提言から主体「私が」・期日「来期中に」を外し、次アクションの**示唆 (動作)** までに置換 / 権限内 (自分の担当範囲) は主体・期日つきで言い切り / 「再設計」「絞り込み」の名詞句止まりを「そろえる案を提出する」の動作に展開 / 「影響とみられる」の受動推量を「ばらつきがある部署ほど低く出ている」という事実の符合に置換し、権限外領域の推量副詞を消した。

**教訓 (確定・4 事例)**: 提言の立場軸は権限性で濃淡が分かれる。自分の担当・決裁権のある案件は動作 + 主体 + 期日まで言い切ってよい。全社処遇・他部門マター・法解釈等の権限外の提言は、次アクションの示唆 (動作) までに留め、主体「私が」・期日の確定は書かない (未合意の約束を報告書に固定しない)。名詞句止まりはどちらの場合も NG — 動作で具体化する。

### 実例: 稟議 — 願望止めを動作の言い切りに

**before** (平均 4.0 → 書き直し):

> 生成 AI ツールの業務活用を推進していきたい。個別の利用申請ごとに承認を得る運用は負荷が大きく、業務効率化を図りたい。

採点: 立場 3 (「推進していきたい」「図りたい」の願望止め) / 具体性 4 / 削減 5。機械ゲート 2 ヒット (稟議の願望止め)。

**after** (平均 7.3):

> 個別申請ごとの承認を、用途カテゴリ単位の包括承認に切り替える。申請のたびに担当者の稟議起票と決裁者の確認稼働が積み上がっており、包括承認によりこの負荷を解消する。

採点: 立場 8 (「切り替える」で言い切り) / 具体性 7 / 削減 7

直した点: 願望止め (「推進していきたい」「図りたい」) を動作の言い切り (「切り替える」) に置換 (「決意表明で締める」の稟議版) / 一般語「業務効率化」を具体の困りごと (稟議起票・確認稼働の積み上がり) に展開。**権限内 (自分の担当稟議) のため言い切ってよい** — 権限外の全社提言なら上記の権限性較正どおり示唆止まりにする。

### 実例: 月次報告の総括 — 格上げ動詞ぼかしを具体施策に

**before** (平均 5.3):

> デジタル推進の取り組みを継続し、各課の運用をさらに進化させ、標準化と横展開を加速させていきたい。

採点: 立場 5 (「進化させる」「加速させる」で何をするか不明) / 具体性 4 / 削減 7。機械ゲート「格上げ動詞ぼかし」ヒット。

**after** (平均 7.7):

> 各課の運用は継続中。次期は課ごとに標準化のチェックリストを配布し、四半期ごとの棚卸しを義務化する。

採点: 立場 7 / 具体性 9 / 削減 7

直した点: 「進化させる」「加速させる」の格上げ動詞を、具体施策 (チェックリスト配布・棚卸し義務化) に展開した。

## 注意

- **提言の立場軸は権限性で決める** (確定・4 事例): 自分の担当・決裁権のある案件は動作 + 主体 + 期日まで言い切る。全社処遇や他部門・法解釈等の権限外の提言は、次アクションの示唆 (動作) までに留め、主体「私が」・期日の確定は書かない。名詞句止まりはどちらの場合も NG
- 数値・事実は裏取りできたものだけ書く (未確認は「未確認」と明示)。報告書での捏造は信頼を一撃で壊す
- 定型フォーマット (会社指定の様式) がある場合は様式に従い、その中の自由記述欄に本 module を適用する。様式の有無が不明なら書き手に確認し、確認できなければ「自由記述と仮定」と成果物に添える
- 議事「録」(逐語) は対象外。議事「要旨」(要約 + 決定事項) が対象
