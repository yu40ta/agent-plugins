# skills

Curated skills for Claude Code and other agent harnesses, published in [agentskills.io](https://agentskills.io) `SKILL.md` format.

This repository mirrors a curated subset of skills from a private source of truth. Skills here are periodically synced — please open issues or PRs for improvements, but note that changes may be superseded by the next sync.

## Usage

This repo follows the agentskills.io `SKILL.md` format and works with any agentskills.io-compatible tool (e.g. `npx skills add`).
